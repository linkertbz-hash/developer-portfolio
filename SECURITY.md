# Publication and security policy

This repository is **public** and contains only approved descriptions of publicly available products and a fully separate educational Python demo.

**Never publish:** source code or copied modules from AVEXIUM, Finansteh or Parser; deployment configs; SSH keys; API tokens or credentials; infrastructure details; database backups; customer information; private analytics; proprietary extraction logic, integration mechanisms or unpublished plans.

The commercial repositories remain private. This public portfolio does **not** grant permission to reuse their source code.

The educational TaskBoard API is a standalone learning example, not production-ready. It has no authentication or tenant isolation and must not be exposed as a public service without those controls.

No open-source license is provided with this repository; please contact the owner about reuse rights.
